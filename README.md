# Hello | Jean Chen's Personal Landing Page

A beautifully designed, premium personal landing page and widget center featuring a real-time clock, dynamic context-aware greetings, theme switching, and interactive 3D elements.

## ✨ Features

- **Glassmorphic Design System**: Modern, visually stunning card UI layered over a fluid background with dynamic animated gradient orbs.
- **Dynamic Time-of-Day Greetings**: Contextually alters greetings (Morning, Afternoon, Evening, Night) with custom inline SVGs matched to your local time.
- **Live Interactive Clock**: Shows hours, minutes, and seconds. Supports seamless switching between 12-hour (AM/PM) and 24-hour formats.
- **Micro-interactions & 3D Tilt**: Interactive 3D hover effects using mouse coordinates that tilt the main interface card, combined with button scaling animations for tactile feedback.
- **Persistent Theme Toggle**: Dual theme engine (Light & Dark mode) that automatically matches system settings and remembers user choices across sessions using `localStorage`.
- **Zero Dependencies**: Lightweight, fast-loading, built purely with semantic HTML5, modern CSS3 variables, and vanilla JavaScript.

## 🚀 Quick Start

To view or host this project locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/ghost199422-max/JEANGITHUB.git
   ```
2. Navigate into the project folder:
   ```bash
   cd JEANGITHUB
   ```
3. Open `index.html` in your favorite web browser (or use VS Code Live Server / standard static file server).

## 🛠️ Built With

- **HTML5**: Structured semantically for optimal SEO and accessibility.
- **Vanilla CSS3**: Leverages CSS Variables (Custom Properties), Keyframe animations, and Backdrop filters for the glassmorphic styling.
- **Vanilla JavaScript**: Handles time state, localStorage persistence, tilt animations, and theme toggling.
